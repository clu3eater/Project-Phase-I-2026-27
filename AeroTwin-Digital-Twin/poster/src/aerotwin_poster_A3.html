Introduction: AeroTwin is an AI-based digital twin that monitors the health of a UAV piston engine (Rotax 915 iS) in real time and warns of faults before any certified alarm limit is crossed. It uses technologies such as Python, a physics-based engine model (Cantera), Machine Learning and Deep Learning (scikit-learn, PyTorch), FastAPI and React to compare every live sensor reading with a healthy “twin” of the engine, detect gradual wear, name the fault, estimate remaining useful life and give a Go / No‑Go decision, fully offline on the drone.

METHODOLOGYFrom raw sensor data to a Go / No-Go decision
1Engine Data
  • Rotax 915 iS with 9 sensor channels
  • 200 engines simulated as they wear out
  • Data streamed over CAN bus
2Edge Checks
  • Decode CANaerospace frames
  • Reject bad sensor values (5 states)
  • Certified limits checked on the drone
3Healthy Twin
  • Physics model with Cantera combustion
  • Predicts what a new engine would read at the same throttle and altitude
4Residuals
  • Gap = actual − healthy
  • Flight conditions cancel out; only the wear is left
  • Taken in sliding windows
✓Output
  • Engine health, fault name and hours left on the React console
GONO-GO
7Validation
  • Trained on 160, tested on 40 unseen engines
  • Precision 0.996, ROC‑AUC 0.989
  • ≈ 1 % false alarms
  • 51 ms per update, 150 KB model
6Diagnosis
  • Names the fault (8 types)
  • Engine health index
  • Remaining useful life (RUL) in hours
5AI Detection
  • Statistical ensemble
  • LSTM autoencoder + deep network
  • Scores fused into one decision

Conclusion: AeroTwin demonstrates how a physics-based digital twin combined with Machine Learning can detect the gradual wear of a UAV piston engine long before a certified alarm limit is crossed. The project improves understanding of engine health monitoring, sensor data validation, anomaly detection, fault diagnosis and remaining-life prediction using Python, PyTorch, FastAPI and React. It also demonstrates a practical, offline and affordable approach to condition-based maintenance that keeps unmanned aircraft safe and mission-ready.
